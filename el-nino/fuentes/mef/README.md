# Archivos originales del MEF

Una carpeta por corte, con la fecha de descarga (`AAAA-MM-DD`). Dentro, los siete archivos tal como los entrega la Consulta Amigable, sin abrir ni modificar, y un `manifiesto.json` con el enlace y la huella SHA-256 de cada uno cuando la descarga es automática.

Estos archivos son la prueba de cada cifra publicada. No se editan: si un archivo está mal, se descarga de nuevo y se reemplaza mediante una propuesta.
